Mongoose is a library that creates a connection between MongoDB and node.js javascript runtime environment

it is a ODM(object data modelling) Library

Schema => Schema defines the shape of the document within that collecition

Model in mongoose is a class with which we construct documents.

Mongoose uses Operation buffering. Mongoose lets you start using your models immediately ,without waiting for mongoose to establish a connection to MongoDB
